# OmniAction (RoboOmni)
- **언어**: 영어 (미확인. 합성 음성 기반)
- **규모**: 141,162 에피소드, 스킬 112개, 객체 748개, 화자 5,000명 이상, 이벤트 소리 2,400개, 배경 소리 640개
- **녹음 환경**: Open-X Embodiment 과제를 GPT-4o로 맥락형 지시문으로 다시 쓰고 음성 합성·검증을 거친 시뮬레이션 데이터. 지시 유형 6개(감정 단서, 겹침 발화, 비언어 단서, 화자 정체 단서, 2인·3인 대화)
- **Physical AI 활용 포인트**: 음성·환경음·시각을 함께 받아 의도를 추론하는 로봇 조작 학습. ASR을 거치지 않는 Speech-VLA 학습 데이터
- **라이선스/연구 이용**: CC BY-NC 4.0 (HF README 기준, 2차 확인). 비상업 연구 가능
- **접근 방식**: 공개 (Hugging Face OpenMOSS-Team/OmniAction)
- **주요 사용 논문**: [RoboOmni, ICLR 2026](../papers/2025-RoboOmni.md)
- **출처**: https://huggingface.co/datasets/OpenMOSS-Team/OmniAction , https://openmoss.github.io/RoboOmni , https://arxiv.org/abs/2510.23763
