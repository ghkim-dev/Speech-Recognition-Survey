# CHiME-4 (CHiME-3 데이터 기반 4th CHiME Challenge)
- **언어**: 영어 (WSJ 문장 낭독)
- **규모**: 출처마다 상이. 학습: 실녹음 약 3시간(4명) + 시뮬레이션 약 15시간(83명), 총 약 18~20시간 (논문별 보고치)
- **녹음 환경**: 6채널 태블릿(전면 5 + 후면 1)으로 버스·카페·교차로·보행자 구역에서 녹음, 근접 마이크 동시 녹음
- **Physical AI 활용 포인트**: 이동 중 소형 디바이스의 다채널 잡음 ASR, 빔포밍 front-end 평가
- **라이선스/연구 이용**: 미확인 (공식 챌린지 페이지 확인 필요)
- **접근 방식**: 신청/챌린지 사이트 (미확인)
- **주요 사용 논문**: 챌린지 요약 논문은 이번에 직접 확인하지 못함
- **출처**: https://signalprocessingsociety.org/publications-resources/data-challenges/chime-2016-4th-chime-speech-separation-and-recognition , https://arxiv.org/pdf/2007.12903
