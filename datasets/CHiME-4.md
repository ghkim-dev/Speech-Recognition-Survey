# CHiME-4 (4th CHiME Speech Separation and Recognition Challenge)
- **언어**: 영어 (WSJ0 5k 문장 낭독)
- **규모**: 학습 실녹음 1,600 + 시뮬레이션 7,138 문장(약 20시간), dev 1,640 / test 1,320 문장(실·시뮬 각각)
- **녹음 환경**: 태블릿 프레임의 6채널 마이크 어레이, 버스·카페·교차로·보행자 구역. 학습 실녹음은 close-talk 마이크 1채널 추가
- **Physical AI 활용 포인트**: 모바일/엣지 디바이스의 다채널 잡음 환경 ASR, 빔포밍 front-end 평가
- **라이선스/연구 이용**: 미확인 (공식 사이트 약관 확인 필요, 원천 WSJ0는 LDC 코퍼스)
- **접근 방식**: 미확인 (챌린지 사이트 신청/LDC 추정)
- **주요 사용 논문**: CHiME-3/4 관련 다채널 ASR front-end 논문 다수 (예: arXiv 1707.00201)
- **출처**: https://signalprocessingsociety.org/publications-resources/data-challenges/chime-2016-4th-chime-speech-separation-and-recognition
