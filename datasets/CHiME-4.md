# CHiME-4
- **언어**: 영어
- **규모**: 학습 약 20시간(실녹음 1,600문장 + 시뮬레이션 7,138문장), 16 kHz
- **녹음 환경**: 6마이크 태블릿(2번 마이크는 후면)에서 WSJ0 5k 문장 낭독. 버스·카페·보행자 구역·거리 4개 환경. 1/2/6채널 트랙
- **Physical AI 활용 포인트**: 이동 중 실외·공공장소 다채널 원거리 ASR, 마이크 수 제약 평가
- **라이선스/연구 이용**: 미확인 (WSJ0 기반이므로 LDC 필요 가능성, 공식 페이지에서 확인 필요)
- **접근 방식**: 미확인 (챌린지 사이트 신청 + LDC WSJ0 추정)
- **주요 사용 논문**: [CHiME-4 mismatch 분석](../papers/2017-CHiME-4-Mismatch-Analysis.md)
- **출처**: https://signalprocessingsociety.org/publications-resources/data-challenges/chime-2016-4th-chime-speech-separation-and-recognition
