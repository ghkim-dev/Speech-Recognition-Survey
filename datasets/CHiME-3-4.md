# CHiME-3 / CHiME-4
- **언어**: 영어 (WSJ0 문장 낭독)
- **규모**: 미확인 (총 시간 출처에서 확인하지 못함)
- **녹음 환경**: 6채널 마이크 탑재 태블릿으로 카페·길거리 교차로·대중교통·보행자 구역에서 실녹음 + 시뮬레이션 데이터. CHiME-4는 동일 데이터에서 테스트 시 사용 마이크 수를 제한
- **Physical AI 활용 포인트**: 모바일/엣지 기기의 다채널 잡음 환경 ASR, 빔포밍 평가
- **라이선스/연구 이용**: 미확인 (WSJ0 기반이므로 LDC 자료 필요 가능성, 공식 사이트에서 확인 필요)
- **접근 방식**: 챌린지 사이트 신청/다운로드 (미확인)
- **주요 사용 논문**: [The third CHiME challenge (ASRU 2015)](../papers/2015-CHiME-3-Challenge.md)
- **출처**: https://hal.archives-ouvertes.fr/hal-01211376 , https://signalprocessingsociety.org/publications-resources/data-challenges/chime-2016-4th-chime-speech-separation-and-recognition
