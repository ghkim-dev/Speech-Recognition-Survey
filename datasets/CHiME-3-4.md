# CHiME-3 / CHiME-4
- **언어**: 영어 (WSJ0 문장 낭독)
- **규모**: 미확인 (검색 결과에 명시 없음)
- **녹음 환경**: 6채널 태블릿 마이크 어레이로 카페·길거리 교차로 등 4개 일상 소음 환경 녹음 (+ 시뮬레이션 데이터). CHiME-4는 CHiME-3 데이터를 재사용하되 테스트 시 사용 가능한 마이크 수를 제한해 난이도를 높임
- **Physical AI 활용 포인트**: 소음 환경의 휴대·엣지 기기 다채널 ASR, 마이크 수 제약 상황 평가
- **라이선스/연구 이용**: 미확인 (WSJ0 기반이라 LDC 자료 필요 가능성, 확인 필요)
- **접근 방식**: 미확인 (공식 CHiME 챌린지 사이트에서 신청/다운로드 추정)
- **주요 사용 논문**: [CHiME-3 Dataset, task and baselines (ASRU 2015)](../papers/2015-CHiME-3.md)
- **출처**: https://hal.archives-ouvertes.fr/hal-01211376 , https://signalprocessingsociety.org/publications-resources/data-challenges/chime-2016-4th-chime-speech-separation-and-recognition
