# CHiME-3 / CHiME-4
- **언어**: 영어 (WSJ0 문장 낭독)
- **규모**: 미확인 (출처 검색 결과에 시간·발화 수 없음)
- **녹음 환경**: 6마이크 태블릿(전면 5개, 후면 1개) + 화자 착용 근접 마이크 1개. 버스·카페·보행자 구간·길거리 등 실제 잡음 환경 + 시뮬레이션 데이터. CHiME-4는 1/2/6채널 ASR 트랙
- **Physical AI 활용 포인트**: 모바일·차량·휴대형 기기의 다채널 잡음 ASR 평가, 마이크 수 제한 실험
- **라이선스/연구 이용**: 미확인 (공식 챌린지 사이트에서 확인 필요; WSJ0 기반이라 LDC 데이터 필요 가능성, 미확인)
- **접근 방식**: 미확인 (챌린지 사이트 신청 추정)
- **주요 사용 논문**: [The third CHiME Challenge: Dataset, task and baselines](../papers/2015-CHiME-3-Challenge.md) (ASRU 2015)
- **출처**: https://hal.archives-ouvertes.fr/hal-01211376 , https://signalprocessingsociety.org/publications-resources/data-challenges/chime-2016-4th-chime-speech-separation-and-recognition
