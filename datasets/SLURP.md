# SLURP (Spoken Language Understanding Resource Package)
- **언어**: 영어
- **규모**: 실제 녹음 약 72K + 합성(TTS) 약 69K 발화(2차 자료), 18 시나리오·46 액션·55 엔티티 유형. 총 시간은 미확인. 오디오 FLAC 약 6GB
- **녹음 환경**: 가정용 개인 로봇 비서 대상 단일 발화 명령. 화자 177명(AMT, 원어민+비원어민), 근접·원거리 헤드셋 조건 포함(세부 미확인)
- **Physical AI 활용 포인트**: 홈 로봇·스마트 스피커의 음성 명령 → 의도/슬롯(SLU) 직접 추출, end-to-end SLU 평가
- **라이선스/연구 이용**: 텍스트 주석 CC BY 4.0, 오디오 CC BY-NC 4.0(비상업 연구 가능, 상업 이용은 Emotech 문의)
- **접근 방식**: 공개 (GitHub 주석 + Zenodo 오디오, `scripts/download_audio.sh`)
- **주요 사용 논문**: SLURP (Bastianelli 외, EMNLP 2020)
- **출처**: https://github.com/pswietojanski/slurp , https://zenodo.org/record/4274930
