# Fluent Speech Commands (FSC)
- **언어**: 영어
- **규모**: 30,043 발화, 97 화자, 약 19시간, 31 의도(action/object/location) — 학습 23,132(77명) / 검증 3,118(10명) / 테스트 3,793(10명), 화자 분리
- **녹음 환경**: 단일 채널 16kHz, 크라우드소싱 근접 녹음(원거리·잡음 조건 아님)
- **Physical AI 활용 포인트**: 스마트홈 기기 제어(조명·음량·언어 설정) 음성 명령의 end-to-end 의도 인식, 엣지 SLU 베이스라인
- **라이선스/연구 이용**: 학술 연구 전용(2차 자료 기준, Fluent.ai 공식 조건 미확인)
- **접근 방식**: 신청 후 다운로드(Fluent.ai 연구 페이지, 직접 확인 못 함)
- **주요 사용 논문**: Speech Model Pre-training for End-to-End SLU (Lugosch 외, Interspeech 2019)
- **출처**: https://fluent.ai/research/fluent-speech-commands/ (접속 불가), https://www.isca-archive.org/interspeech_2019/lugosch19_interspeech.html
