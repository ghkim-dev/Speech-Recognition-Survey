# LibriCSS
- **언어**: 영어 (LibriSpeech 발화를 연결해 시뮬레이션한 대화를 스피커로 재생 후 원거리 마이크로 재녹음)
- **규모**: 미확인(논문 참조)
- **녹음 환경**: 실제 방에서 재녹음한 7채널 원거리 데이터, 다양한 겹침 비율 설정. Kaldi 기반 ASR 평가 스크립트 제공
- **Physical AI 활용 포인트**: 연속 음성 분리(CSS)와 겹침 발화 처리 → 여러 사람이 동시에 말하는 환경의 로봇/디바이스
- **라이선스/연구 이용**: 데이터 자체의 명시적 라이선스는 확인하지 못함(미확인). LibriSpeech 기반이므로 저장소 README/LICENSE 확인 필요
- **접근 방식**: 공개 다운로드 (GitHub: chenzhuo1011/libri_css)
- **주요 사용 논문**: [Continuous speech separation: dataset and analysis (ICASSP 2020)](../papers/2020-LibriCSS-Continuous-Speech-Separation.md)
- **출처**: https://arxiv.org/abs/2001.11482
