# Speech Commands
- **언어**: 영어, 1초 길이 단일 단어 wav(및 배경 잡음)
- **규모**: 총 발화 수는 이번 조사에서 확인하지 못함(미확인, 논문 참조). v2 기준 35개 단어 클래스라는 2차 자료가 있음
- **녹음 환경**: 크라우드소싱, 사용자 기기 마이크 → 환경 다양
- **Physical AI 활용 포인트**: 저전력 엣지 디바이스/로봇의 키워드 검출(KWS), 간단한 음성 명령
- **라이선스/연구 이용**: CC BY 4.0 (Hugging Face 데이터 카드 기준)
- **접근 방식**: 공개 다운로드 (TensorFlow/Hugging Face 등)
- **주요 사용 논문**: Speech Commands: A Dataset for Limited-Vocabulary Speech Recognition (Warden, 2018, arXiv 1804.03209)
- **출처**: https://arxiv.org/abs/1804.03209 , https://huggingface.co/datasets/google/speech_commands
