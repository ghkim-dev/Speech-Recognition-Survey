## 메모
- **브랜치 기준**: 11-27 누적 브랜치(inspiring-keller-iflc3b) 위에서 이어서 작업. main은 여전히 10-29에 머물러 있어 **PR로 main에 병합하는 것을 다시 권장**
- 이번 세션도 arxiv.org, cis.eecs.qmul.ac.uk, *.github.io, lindat.mff.cuni.cz 직접 접속이 막혀 웹 검색 결과로만 확인함. DroFiT 수치(연산 47%·메모리 53% 감소, PESQ +1.2)는 AI 요약 사이트 기준이라 미확인 표기
- AVQ 공개 여부가 엇갈림: QMUL 페이지는 공개라고 하나 DroneAudioSet 논문(2025)은 비공개로 서술. 다운로드 가능 여부 미확인
- 11-27 "다음 후보" 중 DOANet, OORT 차량 명령 데이터는 이번에 다루지 못함
- 발견: Direction-Aware KWS(2026)는 화자 방향을, UAV KWS(2026)는 잡음 바닥을, rotor-conditioned SE(2025)는 로터 상태를 입력으로 주는 "조건화" 설계. 로봇이 이미 아는 정보를 음성 처리에 넣는 흐름이 SE·KWS·사람 감지 전반으로 퍼지는 중. 반면 DroFiT는 조건 없이 경량화에 집중해, 두 접근을 실제 비행 녹음에서 비교한 연구는 아직 찾지 못함
- 동향: 드론 청각 데이터가 실내 음향만(DREGON) → 실외 시청각(AVQ) → 대규모 실제 회전 녹음(DroneAudioSet)으로 확장. KWS 쪽은 단일 채널 → 다채널+방향(KWDOA, Direction-Aware KWS)으로 이동
