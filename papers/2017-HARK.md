# Development, Deployment and Applications of Robot Audition Open Source Software HARK
- **저자**: Kazuhiro Nakadai, Hiroshi G. Okuno, Takeshi Mizumoto (Honda Research Institute Japan, 도쿄공대·와세다 겸직 등 — 세부 소속 미확인) / **Journal of Robotics and Mechatronics, Vol. 29, No. 1, pp. 16-25, 2017** (Fuji Press). IEEE 계열 아님(보조 출처)
  - 관련 선행: Nakadai, Okuno, Nakajima, Hasegawa, Tsujino, "An open source software system for robot audition HARK and its evaluation", **IEEE-RAS Humanoids 2008**, pp. 561-566 (최초 공개 논문, IEEE 계열) / Nakadai 외, "Design and Implementation of Robot Audition System 'HARK'", Advanced Robotics 24(5-6): 739-761, 2010
- **문제**: 로봇이 자기 귀(내장 마이크 어레이)로 여러 화자를 동시에 듣고 인식하려면 위치 추정·분리·인식을 통합한 실시간 시스템이 필요하지만, 연구자가 바로 쓸 공통 소프트웨어가 없었음
- **방법**: HARK(HRI-JP Audition for Robots with Kyoto Univ.; 문헌에 따라 "Honda Research Institute Japan Audition for Robots with Kyoto University"로도 표기)는 FlowDesigner 기반 GUI로 모듈을 연결해 로봇 청각 시스템을 구성하는 오픈소스 미들웨어. 핵심 기능은 음원 위치 추정(MUSIC 계열), 음원 분리(GSS 등), ASR 연동(Julius, 이후 Kaldi). 2017 논문은 10여 년의 개발·보급 과정과 임베디드용 **HARK-Embedded**, 클라우드 서비스형 **HARK-SaaS**를 정리하고 응용 사례를 소개. 이후 버전에서 Python 인터페이스(PyHARK, HARK 3.4) 추가(2023 국내 논문 기준)
- **데이터셋/평가**: 특정 공개 벤치마크가 아닌 응용 사례 중심(세부 실험 수치는 원문 미확인). HARK MUSIC은 LOCATA 챌린지(2018) 참가 보고서에도 사용됨
- **결과**: 2008년 연구용 오픈소스로 공개, 매년 업데이트. Honda HEARBO 로봇에서 최대 4개 음원을 동시에 약 1° 정확도로 위치 추정(언론 보도 기준, 미확인). 다운로드·사용자 수 통계는 미확인
- **공개 여부**: 연구 목적 무료 오픈소스, 상업적 이용은 별도 라이선스(2010 ROS 블로그 기준 — 현재 조건 미확인). ROS 연동 패키지 존재. 공식 사이트 hark.jp 직접 접속 불가
- **Physical AI 시사점**: ODAS(11-23)가 비교 대상으로 삼은 로봇 청각 프레임워크의 원조. "위치 추정 → 분리 → ASR"을 하나의 그래프로 묶어 로봇에 붙이는 설계는 현재 로봇 음성 인터페이스 구조의 표준형이며, HARK-Embedded/SaaS는 엣지 처리 vs 클라우드 처리 분할 문제를 일찍 다룬 사례. 계산량이 커서 저가 보드에 부적합하다는 한계가 ODAS 개발 동기가 됨
