# ODAS: Open embeddeD Audition System
- **저자**: François Grondin, Dominic Létourneau, Cédric Godin, Jean-Samuel Lauzon, Jonathan Vincent, Simon Michaud, Samuel Faucher, François Michaud (IntRoLab, Université de Sherbrooke — 저장소 저작권 표기의 usherbrooke.ca 주소 기준) / **Frontiers in Robotics and AI, vol. 9, 854444, 2022-05-11** (doi:10.3389/frobt.2022.854444), arXiv 2103.03954 (2021-03). IEEE 계열은 아님(보조 출처)
- **문제**: 기존 로봇 청각 프레임워크(ManyEars, HARK 등)는 계산량이 커서 저가 임베디드 보드에서 다채널 실시간 처리가 어려움
- **방법**: C로만 작성(외부 의존성 FFTW3 하나)한 로봇 청각 라이브러리. 파이프라인은 (1) 음원 위치 추정(SSL, SRP-PHAT-HSDA), (2) 추적(SST, 수정 3D 칼만 필터 M3K), (3) 분리·후처리 필터(SSS) 3단 캐스케이드 + 웹 시각화(odas_web). ManyEars 후속. 폐쇄형 어레이에서는 마주보는 마이크 쌍을 제외해 상호상관을 일부 쌍만 계산(예: 28쌍 중 20쌍 → 상호상관 계산량 29% 감소)
- **데이터셋/평가**: 자체 로봇·어레이 실측(8SoundsUSB·16SoundsUSB 오픈 하드웨어 어레이 등). 공개 벤치마크(LOCATA 등) 사용 여부는 미확인
- **결과**: Raspberry Pi 3 단일 코어 기준 칼만 기반 추적으로 부하가 음원 1개 추적 시 약 24% → 0.8%, 4개 추적 시 약 98% → 7%로 감소(검색 요약 기준, 이전 연구 인용 수치일 수 있음 — 미확인). 선행 논문(Grondin & Michaud, Robotics and Autonomous Systems 2019, arXiv 1812.00115)에서 SRP-PHAT-HSDA는 16마이크 폐쇄 어레이에서 SRP-PHAT 대비 CPU 약 4배 절감(SRP-PHAT은 12마이크 초과 시 온라인 불가), M3K는 기존 추적기 대비 최대 30배 적은 연산으로 동등 이상 성능. 분리(GSS) 단계 수치는 미확인
- **공개 여부**: 코드 MIT 라이선스, https://github.com/introlab/odas (ROS 래퍼 odas_ros, GUI odas_web 별도 저장소). raw.githubusercontent.com으로 README·LICENSE 직접 확인
- **Physical AI 시사점**: 로봇·엣지 기기에서 "위치 추정 → 추적 → 분리"를 저전력으로 돌리는 공개 기준 구현. 분리된 화자별 스트림을 ASR/KWS에 넘기는 로봇 원거리 음성 인터페이스의 앞단으로 바로 쓸 수 있고, ROS 연동이 되어 있어 이동 로봇 통합 비용이 낮음. 11-22 Lend me an Ear의 Grondin과 같은 연구실 계보로 판단(저자명·연구실 일치 기반 추정)
