# Towards the Vision-Sound-Language-Action Paradigm: The HEAR Framework for Sound-Centric Manipulation
- **저자**: Chang Nie, Tianchen Deng, Guangming Wang, Zhe Liu, Hesheng Wang (상하이교통대, 케임브리지대) / arXiv 2026-03, IJRR 2026 게재 승인(저장소 기준)
- **문제**: action chunking의 open-loop 실행 중 이산 오디오 관측 창 사이에서 음향 이벤트가 유실되는 "Blind Execution Interval"
- **방법**: Historizer(스트리밍 인과 오디오 메모리), Envisioner(시각·언어·고유감각·오디오 계층적 멀티모달 추론), Advancer(미래 오디오 코드 예측 오디오 월드모델, 학습 시), Realizer(conditional flow matching 행동 청크 생성)
- **데이터셋/벤치마크**: OpenX-Sound(OXE+동기화 오디오, HF 공개), HEAR-Bench(RoboTwin 2.0 기반 7개 과제, 4가지 음향 큐: 경보 이벤트·음성/운율·연속 공정음·물리 접촉 피드백, 큐 이전 행동은 실패 처리)
- **결과**: 벤치마크 수치 미확인(arXiv 직접 접속 불가). OpenX-Sound 동기화 정확도 98.7%(100ms 허용)
- **Physical AI 시사점**: 음성 명령뿐 아니라 음성 운율·환경음을 VLA 실행 루프에 스트리밍으로 연결. 모델(Qwen3-Omni 기반 등)·코드(Apache-2.0) 공개
- **링크**: https://arxiv.org/abs/2603.16086 , https://github.com/IRMVLab/HEAR
