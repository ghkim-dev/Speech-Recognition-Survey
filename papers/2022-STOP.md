# STOP: A Dataset for Spoken Task Oriented Semantic Parsing
- **저자**: Paden Tomasello 외 (Meta AI) / IEEE SLT 2022 (Doha, 2023-01, pp. 991–998)
- **문제**: 기존 E2E SLU 데이터셋(FSC, SLURP 등)은 평면적 의도·슬롯 위주이고 규모·화자 수가 제한적. 복합 명령의 계층 구조를 다루는 공개 음성 데이터가 부족함
- **방법**: TOPv2 텍스트 의미 파스에 대응하는 대규모 음성 데이터를 수집. exact match(의도·슬롯 라벨과 슬롯 텍스트가 모두 일치) 지표로 cascade(ASR→NLU)와 E2E 모델 베이스라인을 제공하고, 저자원 도메인 적응 split 구성
- **데이터셋/벤치마크**: [STOP](../datasets/STOP.md)
- **결과**: 베이스라인 exact match 수치는 미확인(arXiv·ar5iv 직접 접속 불가)
- **Physical AI 시사점**: IEEE 계열에서 공개된 가장 큰 SLU 음성 벤치마크 중 하나. 로봇 명령을 행동 계획에 가까운 트리 구조로 파싱하는 연구의 기준선
- **링크**: https://arxiv.org/abs/2207.10643 , https://facebookresearch.github.io/spoken_task_oriented_parsing/docs/semantic_parsing
