# Continuous Speech Separation: Dataset and Analysis
- **저자**: Zhuo Chen, Takuya Yoshioka 외 / ICASSP 2020 (IEEE)
- **문제**: 연속 대화에서 겹침 발화를 분리해 ASR에 연결하는 평가용 표준 데이터 부재
- **방법**: LibriSpeech 발화를 연결한 시뮬레이션 대화를 원거리 재녹음한 LibriCSS와 Kaldi 기반 평가 프로토콜 공개
- **데이터셋**: [LibriCSS](../datasets/LibriCSS.md)
- **Physical AI 시사점**: 다화자 환경 로봇의 음성 분리 front-end 평가에 사용 가능
- **링크**: https://arxiv.org/abs/2001.11482
