# SLURP: A Spoken Language Understanding Resource Package
- **저자**: Emanuele Bastianelli, Andrea Vanzo, Pawel Swietojanski, Verena Rieser / EMNLP 2020 (pp. 7252–7262)
- **문제**: 기존 SLU 데이터셋(ATIS, Snips, FSC 등)은 규모·언어 다양성·도메인이 제한적
- **방법**: 가정용 로봇 비서 시나리오의 18개 도메인 SLU 데이터셋 구축, 엔티티 평가용 SLU-F1 지표 제안, ASR+NLU 파이프라인 베이스라인 제공
- **데이터셋/벤치마크**: SLURP
- **결과**: 세부 수치 미확인(arXiv 직접 접속 불가)
- **Physical AI 시사점**: 홈 로봇 음성 명령을 의도·엔티티 수준에서 평가하는 표준 벤치마크
- **링크**: https://aclanthology.org/2020.emnlp-main.588/ (ACL ID 미확인), https://arxiv.org/abs/2011.13205
